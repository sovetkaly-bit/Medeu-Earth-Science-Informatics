# Restricted/independently supplied data
KazEOSat-1/2 imagery, registered JAXA AW3D30 tiles, and independent bare-earth DTM/LiDAR must be supplied according to provider licensing. DO NOT commit restricted raw scenes to public GitHub. For analysis, provenance must record acquisition date, licensing, product level, CRS, vertical datum, acquisition epoch, resolution, cloud/snow mask, transformations, and file SHA-256. The default pipeline does NOT present DSM or NASAdem as independent ground truth. For proper independent validation, add an approved reference DTM and implement withheld-geometry spatial CV; this package intentionally does not claim to have run it.
