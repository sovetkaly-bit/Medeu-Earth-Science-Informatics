# Data and Code Availability (for the manuscript; insert the DOI only after Zenodo publication is confirmed)

All code, configurations, stored result tables and cartographic products supporting this study are available in the public GitHub repository https://github.com/sovetkaly-bit/Medeu-Earth-Science-Informatics. Each computational stage is stored on its own branch together with the GitHub Actions run that produced it: primary lidar validation (branch r40-results, run 38058021115), ICESat-2 ATL08 extraction (r40-icesat2, run 38062602638), ICESat-2 risk–coverage evaluation (r40-icesat2-riskcov, run 38071303684), additional statistical checks (r40-extra, run 38074462352), the first cartographic source package (r40-cartography-results, run 38078170104) and the journal map edition (code commit 63d9dbfd55c3d43aeaf3bad527aa03907a0c3a01 on branch r40-cartography, run 38084018547). A versioned archive containing the code, stored tables, journal figures in PNG/PDF/SVG, source geodata that may be redistributed, a file manifest with SHA-256 checksums and the git history is deposited at Zenodo: [DOI TO BE INSERTED AFTER PUBLICATION].

The archive contains derived 30 m rasters, vector layers and tables; third-party source terms apply: Copernicus GLO-30 (contains modified Copernicus data), NASADEM, swissALTI3D (swisstopo OGD), USGS 3DEP, OpenStreetMap (© OpenStreetMap contributors, ODbL 1.0), Natural Earth and NASA ICESat-2 ATL08 v007. ALOS AW3D30 and FABDEM rasters are not redistributed because of licence terms; only derived statistics are included and the acquisition code is provided. KazEOSat imagery was not used. Kazakhstan has no independent lidar terrain model; the Kazakhstan maps show transferred classifications and are not validated. Resort outlines are exploratory OpenStreetMap or derived footprints, not official boundaries.
